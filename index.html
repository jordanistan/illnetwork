WELCOME, OPERATOR

Know what is running

ill.network is a straightforward security and health audit for your Linux systems. Take a useful snapshot, understand the signal, and make the next move.

This page is a small love letter to the weird, useful web — with a security console hiding underneath. No account, no dashboard maze, no cloud required for the first pass.

▸ Get scanning

Open a terminal on the machine you want to check and run:

curl -sSL https://raw.githubusercontent.com/jordanistan/illnetwork/main/setup.sh | bash

The installer starts the local console and prints the address. Keep this page open while the checks run, then return here for the report archive.
